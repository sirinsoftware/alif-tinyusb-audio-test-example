2. TinyUSB sources vendored into the examples
---------------------------------------------
Each example directory carries its own copy of a small number of TinyUSB
files, so that the examples build against a pinned version of the USB audio
class driver rather than the one in the submodule:

  audio_test/src/, audio_test_freertos/src/, audio_test_zephyr/src/
    audio.h              unmodified TinyUSB source
    usb_descriptors.c    unmodified TinyUSB source
    audio_device.c       TinyUSB source, modified in this project
    audio_device.h       TinyUSB source, modified in this project
    main.c               TinyUSB example source, modified in this project
    tusb_config.h        TinyUSB example source, modified in this project

Licence:      MIT, see LICENSE-MIT.txt.
Copyright:    the copyright notices in these files name Ha Thach
              (tinyusb.org), Reinhard Panhuber, Jerzy Kasenberg and
              HiFiPhile. Those notices are retained unchanged.
Modifications: developed for the Alif Semiconductor platform; see the per-file
              notices and README.md.

The same applies to test/plot_audio_samples.py, which derives from the
TinyUSB example script of the same name, and to
audio_test_zephyr/cmake/family_support.cmake and
audio_test_zephyr/cmake/tinyusb_sources.cmake, which derive from the TinyUSB
CMake build support files.
